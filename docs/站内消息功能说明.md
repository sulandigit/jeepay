# 站内消息功能使用说明

## 功能概述

本系统实现了基于WebSocket的站内消息实时推送功能,支持系统消息、通知消息、告警消息等多种类型的消息推送。

## 主要功能

### 1. 消息类型
- **系统消息** (TYPE_SYSTEM = 1): 系统级别的重要通知
- **通知消息** (TYPE_NOTICE = 2): 一般性通知信息
- **告警消息** (TYPE_ALERT = 3): 需要用户关注的告警信息
- **自定义消息** (TYPE_CUSTOM = 9): 自定义类型消息

### 2. 推送方式
- **全体推送** (PUSH_TYPE_ALL = 1): 向所有在线用户广播消息
- **指定用户推送** (PUSH_TYPE_SPECIFIC = 2): 向特定用户发送消息

### 3. 消息状态
- **未读** (STATE_UNREAD = 0): 消息未被查看
- **已读** (STATE_READ = 1): 消息已被查看

```sql

```

表结构包含以下字段:
- `msg_id`: 消息ID (主键,自增)
- `title`: 消息标题
- `content`: 消息内容
- `msg_type`: 消息类型
- `receiver_user_id`: 接收用户ID
- `receiver_username`: 接收用户名
- `sender_user_id`: 发送用户ID
- `sender_username`: 发送用户名
- `state`: 消息状态 (0-未读, 1-已读)
- `push_type`: 推送方式
- `sys_type`: 所属系统 (MGR-运营平台, MCH-商户中心)
- `read_time`: 读取时间
- `created_at`: 创建时间
- `updated_at`: 更新时间

## API接口说明

### 1. 获取消息列表
```
GET /api/sysMessages
```

参数:
- `pageNumber`: 分页页码 (默认: 1)
- `pageSize`: 分页条数 (默认: 20)
- `title`: 消息标题 (可选)
- `msgType`: 消息类型 (可选)
- `state`: 消息状态 (可选)

### 2. 获取未读消息数量
```
GET /api/sysMessages/unreadCount
```

### 3. 获取消息详情
```
GET /api/sysMessages/{msgId}
```

### 4. 发送消息
```
POST /api/sysMessages
```

请求体:
```json
{
  "title": "消息标题",
  "content": "消息内容",
  "msgType": 1,
  "pushType": 2,
  "receiverUserId": 100001,
  "receiverUsername": "用户名"
}
```

### 5. 标记消息为已读
```
PUT /api/sysMessages/{msgId}/read
```

### 6. 批量标记消息为已读
```
PUT /api/sysMessages/batchRead
```

参数:
- `msgIds`: 消息ID列表 (逗号分隔)

### 7. 删除消息
```
DELETE /api/sysMessages/{msgId}
```

### 8. 获取在线人数
```
GET /api/sysMessages/onlineCount
```

## WebSocket使用说明

### 1. WebSocket连接地址
```
ws://{host}:{port}/websocket/message/{userId}
```

示例:
```
ws://localhost:9217/websocket/message/100001
```

### 2. 连接方式

JavaScript示例:
```javascript
const userId = '100001';
const ws = new WebSocket(`ws://localhost:9217/websocket/message/${userId}`);

// 连接成功
ws.onopen = function(event) {
    console.log('WebSocket连接成功');
};

// 接收消息
ws.onmessage = function(event) {
    const data = JSON.parse(event.data);
    console.log('收到消息:', data);
};

// 发生错误
ws.onerror = function(error) {
    console.error('WebSocket错误:', error);
};

// 连接关闭
ws.onclose = function(event) {
    console.log('WebSocket连接关闭');
};
```

### 3. 消息格式

接收到的消息格式:
```json
{
  "type": "message",
  "msgId": 1,
  "title": "消息标题",
  "content": "消息内容",
  "msgType": 1,
  "createdAt": "2025-01-01 12:00:00"
}
```

### 4. 心跳机制

客户端可以发送心跳消息保持连接:
```javascript
ws.send('ping');  // 服务端会返回 'pong'
```

## 注意事项

1. **权限控制**
   - 消息列表查询需要 `ENT_MESSAGE_LIST` 权限
   - 消息发送需要 `ENT_MESSAGE_SEND` 权限
   - 消息删除需要 `ENT_MESSAGE_DELETE` 权限

2. **消息安全**
   - 用户只能查看自己的消息或全体推送的消息
   - 标记已读时会验证消息所属用户
   - 删除消息需要管理员权限

3. **性能优化**
   - 消息列表使用分页查询
   - WebSocket连接使用ConcurrentHashMap存储
   - 数据库表添加了索引优化查询

4. **异常处理**
   - WebSocket异常会记录到日志
   - 消息发送失败会返回错误信息
   - 断线重连需要客户端实现
