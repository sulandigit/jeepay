# 站内消息功能 - 快速开始

## 一、安装步骤

### 1. 执行数据库脚本
```bash
# 进入项目目录
cd /data/workspace/jeepay

# 执行SQL脚本创建消息表
mysql -u用户名 -p密码 数据库名 < docs/sql/t_sys_message.sql
```

### 2. 编译项目
```bash
# 编译整个项目
mvn clean install -DskipTests

# 或者只编译manager模块
cd jeepay-manager
mvn clean package -DskipTests
```

### 3. 启动服务
```bash
cd jeepay-manager
mvn spring-boot:run
```

### 方式2: 使用API接口

#### 发送消息给指定用户
```bash
curl -X POST http://localhost:9217/api/sysMessages \
  -H "Content-Type: application/json" \
  -H "iToken: YOUR_TOKEN" \
  -d '{
    "title": "测试消息",
    "content": "这是一条测试消息",
    "msgType": 1,
    "pushType": 2,
    "receiverUserId": 100001,
    "receiverUsername": "admin"
  }'
```

#### 发送消息给所有用户
```bash
curl -X POST http://localhost:9217/api/sysMessages \
  -H "Content-Type: application/json" \
  -H "iToken: YOUR_TOKEN" \
  -d '{
    "title": "系统通知",
    "content": "这是一条系统广播消息",
    "msgType": 1,
    "pushType": 1
  }'
```

#### 查询消息列表
```bash
curl -X GET "http://localhost:9217/api/sysMessages?pageNumber=1&pageSize=10" \
  -H "iToken: YOUR_TOKEN"
```

#### 获取未读消息数量
```bash
curl -X GET http://localhost:9217/api/sysMessages/unreadCount \
  -H "iToken: YOUR_TOKEN"
```

#### 标记消息为已读
```bash
curl -X PUT http://localhost:9217/api/sysMessages/1/read \
  -H "iToken: YOUR_TOKEN"
```

#### 批量标记已读
```bash
curl -X PUT "http://localhost:9217/api/sysMessages/batchRead?msgIds=1,2,3" \
  -H "iToken: YOUR_TOKEN"
```

## 三、前端集成示例

### JavaScript WebSocket客户端

```javascript
class MessageClient {
    constructor(userId) {
        this.userId = userId;
        this.ws = null;
        this.reconnectTimer = null;
    }

    // 连接WebSocket
    connect() {
        const wsUrl = `ws://localhost:9217/websocket/message/${this.userId}`;
        this.ws = new WebSocket(wsUrl);

        this.ws.onopen = () => {
            console.log('WebSocket连接成功');
            this.startHeartbeat();
        };

        this.ws.onmessage = (event) => {
            const data = JSON.parse(event.data);
            this.handleMessage(data);
        };

        this.ws.onerror = (error) => {
            console.error('WebSocket错误:', error);
        };

        this.ws.onclose = () => {
            console.log('WebSocket连接关闭');
            this.reconnect();
        };
    }

    // 处理接收到的消息
    handleMessage(data) {
        if (data.type === 'message') {
            // 显示消息通知
            this.showNotification(data);
            // 更新未读数量
            this.updateUnreadCount();
        }
    }

    // 显示消息通知
    showNotification(data) {
        // 实现消息提示逻辑
        console.log('新消息:', data);
    }

    // 更新未读数量
    updateUnreadCount() {
        fetch('/api/sysMessages/unreadCount', {
            headers: { 'iToken': 'YOUR_TOKEN' }
        })
        .then(res => res.json())
        .then(data => {
            // 更新界面上的未读数量标记
            console.log('未读消息数:', data.data);
        });
    }

    // 心跳保活
    startHeartbeat() {
        setInterval(() => {
            if (this.ws && this.ws.readyState === WebSocket.OPEN) {
                this.ws.send('ping');
            }
        }, 30000); // 每30秒发送一次心跳
    }

    // 断线重连
    reconnect() {
        if (this.reconnectTimer) return;
        
        this.reconnectTimer = setTimeout(() => {
            console.log('尝试重新连接...');
            this.connect();
            this.reconnectTimer = null;
        }, 5000); // 5秒后重连
    }

    // 断开连接
    disconnect() {
        if (this.ws) {
            this.ws.close();
            this.ws = null;
        }
    }
}

// 使用示例
const messageClient = new MessageClient('100001');
messageClient.connect();
```

### Vue.js集成示例

```vue
<template>
  <div class="message-center">
    <el-badge :value="unreadCount" :hidden="unreadCount === 0">
      <el-button icon="el-icon-bell" @click="showMessages">消息</el-button>
    </el-badge>

    <el-drawer
      title="消息中心"
      :visible.sync="drawer"
      direction="rtl"
      size="400px">
      <el-tabs v-model="activeTab">
        <el-tab-pane label="全部消息" name="all">
          <message-list :messages="messages" @read="handleRead" />
        </el-tab-pane>
        <el-tab-pane label="未读消息" name="unread">
          <message-list :messages="unreadMessages" @read="handleRead" />
        </el-tab-pane>
      </el-tabs>
    </el-drawer>
  </div>
</template>

<script>
export default {
  name: 'MessageCenter',
  data() {
    return {
      ws: null,
      drawer: false,
      activeTab: 'all',
      unreadCount: 0,
      messages: [],
      unreadMessages: []
    }
  },
  mounted() {
    this.connectWebSocket();
    this.loadMessages();
  },
  beforeDestroy() {
    if (this.ws) {
      this.ws.close();
    }
  },
  methods: {
    // 连接WebSocket
    connectWebSocket() {
      const userId = this.$store.state.user.userId;
      this.ws = new WebSocket(`ws://localhost:9217/websocket/message/${userId}`);
      
      this.ws.onmessage = (event) => {
        const data = JSON.parse(event.data);
        if (data.type === 'message') {
          this.$notify({
            title: data.title,
            message: data.content,
            type: this.getNotifyType(data.msgType)
          });
          this.loadMessages();
        }
      };
    },

    // 加载消息列表
    async loadMessages() {
      const res = await this.$http.get('/api/sysMessages');
      this.messages = res.data.records;
      this.unreadMessages = this.messages.filter(m => m.state === 0);
      this.unreadCount = this.unreadMessages.length;
    },

    // 显示消息列表
    showMessages() {
      this.drawer = true;
    },

    // 标记已读
    async handleRead(msgId) {
      await this.$http.put(`/api/sysMessages/${msgId}/read`);
      this.loadMessages();
    },

    // 获取通知类型
    getNotifyType(msgType) {
      const types = {
        1: 'info',
        2: 'success',
        3: 'warning',
        9: 'info'
      };
      return types[msgType] || 'info';
    }
  }
}
</script>
```

## 四、配置说明

### WebSocket配置
WebSocket端点默认路径: `/websocket/message/{userId}`

如需修改,编辑文件:
```
jeepay-manager/src/main/java/com/jeequan/jeepay/mgr/websocket/MessageWebSocketServer.java
```

修改注解中的路径:
```java
@ServerEndpoint("/websocket/message/{userId}")
```

## 五、常见问题

### Q1: WebSocket连接失败
**解决方法:**
- 检查服务是否正常启动
- 检查端口是否正确 (默认9217)
- 检查防火墙设置
- 检查nginx代理配置(如果使用)

### Q2: 消息发送失败
**解决方法:**
- 检查数据库连接
- 检查表是否创建成功
- 检查用户是否有发送权限
- 查看后台日志错误信息

### Q3: 收不到实时消息
**解决方法:**
- 检查WebSocket是否连接成功
- 检查用户ID是否正确
- 检查消息推送类型是否正确
- 检查浏览器控制台错误信息

### Q4: nginx代理WebSocket配置
```nginx
location /websocket/ {
    proxy_pass http://localhost:9217;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_connect_timeout 60s;
    proxy_send_timeout 60s;
    proxy_read_timeout 60s;
}
```

## 六、生产环境建议

1. **消息持久化**: 定期清理过期消息,避免数据库膨胀
2. **负载均衡**: 使用Redis Pub/Sub实现多实例消息同步
3. **监控告警**: 监控WebSocket连接数和消息发送量
4. **安全加固**: 
   - 启用WSS加密传输
   - 添加Token验证
   - 限制连接频率
5. **性能优化**:
   - 合理设置消息保留时间
   - 添加消息缓存
   - 优化数据库索引
