## 十、使用流程

### 发送消息流程
1. 管理员通过API发送消息
2. SysMessageController接收请求
3. 调用SysMessageService保存消息到数据库
4. 根据推送类型,通过MessageWebSocketServer实时推送
5. 在线用户立即收到消息

### 接收消息流程
1. 用户登录系统
2. 前端建立WebSocket连接
3. MessageWebSocketServer管理连接
4. 新消息到达时实时推送到客户端
5. 客户端显示消息并更新未读数量

## 十一、权限要求

需要在系统中配置以下权限:
- `ENT_MESSAGE_LIST` - 查看消息列表
- `ENT_MESSAGE_SEND` - 发送消息
- `ENT_MESSAGE_DELETE` - 删除消息
